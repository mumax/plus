mumax+#

Welcome to the documentation!#

mumax⁺ is a versatile and extensible GPU-accelerated micromagnetic simulator written in C++ and CUDA with a Python interface. This project is in development alongside mumax³. If you have any questions, feel free to use the mumax⁺ GitHub Discussions.

Citations#

mumax+ is described in the following paper:

mumax+: extensible GPU-accelerated micromagnetics and beyond

https://www.nature.com/articles/s41524-025-01893-y

Please cite this paper if you would like to cite mumax+. All demonstrations in the paper were simulated using version v1.1.0 of the code. The scripts used to generate the data can be found in the paper2025 directory under the paper2025 tag.

GPU Performance#

mumax+ is cross-platform and runs on Linux and Windows platforms. All installation instructions can be found on the installation page. You will need an NVIDIA GPU and the benchmark below may guide your GPU choice.

Number of cells:

If you would like to contribute your GPU benchmark to this figure, run examples/bench.py and share the contents of the resulting bench.txt file here. If you have multiple different GPUs in your system, you can use the optional flag --all to benchmark them all. Even if your GPU is already included in the list, we appreciate additional benchmarks, as they allow us to estimate and display error bars in the figure.
